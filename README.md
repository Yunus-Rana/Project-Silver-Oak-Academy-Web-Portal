# Silver Oak Academy Web Portal

## Overview
A comprehensive front-end implementation of a modern educational website. This project transitions from simple scripting into full-scale web architecture, featuring multiple interconnected pages, a functional admission system interface, and a responsive design language.

## Technical Stack
* **HTML5:** Semantic structure for multi-page navigation.
* **CSS3:** Custom design systems utilizing:
    * **CSS Variables:** For consistent color branding (`--primcolor`, `--seccolor`).
    * **Flexbox & CSS Grid:** For complex, responsive layouts (Gallery and Teacher cards).
    * **State Effects:** Interactive hover states and transitions for buttons and links.
* **Assets:** Custom branding and curated photography integration.

## Project Architecture
The project is structured to maintain a distinct separation of concerns, with specific stylesheets for different site modules:
* `index.html` / `style.css`: The central landing experience with hero sections and performance stats.
* `about.html` / `about.css`: Detailed departmental breakdowns, facilities grid, and staff profiles.
* `admission.html` / `admission.css`: A comprehensive user input system featuring a structured admission form with validation-ready fields.

## Key Features
* **Multi-Page Navigation:** A synchronized header/footer system across all pages.
* **Departmental Cards:** High-impact visual cards with box-shadow depth.
* **Admission System:** A clean, user-centric form design with radio buttons, dropdowns, and checkboxes for data acquisition.
* **Responsive Gallery:** A grid-based layout for showcasing campus environments.

## How To Run
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. Navigate through the header links to explore the full site architecture.
